# Contribuer

## Flux de contribution

1. Sur le site, cliquez sur le bouton ✏️ d'une page pour la modifier directement sur GitHub.
2. Pour un nouveau sujet, créez un fichier Markdown dans `docs/sujets/`.
3. Ajoutez la page dans la section `nav` de `mkdocs.yml`.
4. Ouvrez une Pull Request ; elle sera relue avant fusion.

## Règles

- **Sources citées** : toute affirmation factuelle doit être sourcée.
- **Neutralité** : présentez les faits et les positions sans prise de parti.
- **Un sujet par page** : gardez des pages ciblées.

Le guide détaillé se trouve dans [docs/contribuer.md](docs/contribuer.md).
