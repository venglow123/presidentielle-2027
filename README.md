# Présidentielle 2027 – Wiki

Wiki collaboratif en français sur l'élection présidentielle de 2027, construit avec [MkDocs Material](https://squidfunk.github.io/mkdocs-material/).

🌐 Site : <https://venglow123.github.io/presidentielle-2027/>

## Développement local

```bash
python -m venv .venv
# Windows : .venv\Scripts\activate  |  Linux/macOS : source .venv/bin/activate
pip install -r requirements.txt
mkdocs serve
```

Le site est alors disponible sur <http://127.0.0.1:8000>.
